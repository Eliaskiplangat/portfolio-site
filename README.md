# Portfolio Site

My personal portfolio: [Elias Kiplangat, Backend Developer](https://github.com/Eliaskiplangat).

Live site: elias-kiplangat-portfolio.netlify.app

## About

A static site that presents my backend projects, experience and skills (Java and Spring Boot, Elixir and Phoenix, Docker), with a link to my resume.

## Contents

- `index.html`: page markup
- `bundle.js`: bundled JavaScript
- `Elias_Kiplangat_Resume.pdf`: downloadable resume

## Run locally

```bash
git clone https://github.com/Eliaskiplangat/portfolio-site.git
cd portfolio-site
```

Open `index.html` in a browser, or serve the folder with any static server.
